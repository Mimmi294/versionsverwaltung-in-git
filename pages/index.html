Home

Auf dieser Seite möchte ich git vorstellen, ein wunderbares Werkzeug um Versionen von Dateien zu verwalten. Diese gesamte Seite wurde mithilfe von git entwickelt und kann hier eingesehen und heruntergeladen werden.

Initialisierung eines Repositorys

Zu Beginn installierte ich zunächst git und befolgte die Anweisungen auf folgendem Link.
Gerade zu beginn ist es ratsam mit der Benutzeroberfläche GitHub Desktop zu arbeiten. GitHub Desktop greift auf die Funktionen und Daten von git zu und stellt diese Vereinfacht da, was gerade für Anfänger wesentlich einfacher sein kann, um sich zurecht zu finden.
Da ich die einzelnen Schritte nur abstrakt erkläre, verlinke ich spezifischere Anleitung als Hilfestellung.
Um mit meinem Projekt zu starten, initialisierte ich ein neues Repository. Das Repository bezeichnet mein gesamtes Projekt, inklusive des Codes, verschiedener Anhänge, den Versionsverlauf und organisatorische Informationen, die git helfen das Projekt zu verwalten.
Nachdem das Repository nun erstellt ist, befinden sich zunächst keine inhaltsbezogenen Daten darin - lediglich organisatorische Dateien für die Strukturierung des Projekts. Nach der Initialisierung ist das Repository vorerst nur lokal gespeichert, was dazu führt, dass es nicht ohne weiteres von anderen Geräten einsehbar ist.

Geschichte


Gründer

Name: Linus Torvalds
Alter: geboren am 28.Dezember 1969 (56)
Beruflicher Gang: Linus Torvalds ist ein finnisch-US-amerikanischer Informatiker und Software-Entwickler.

Git

In der britischen Umgangssprache bedeutet „git“ so viel wie „Blödmann“. Herr Torvalds begründete seine Wahl damit, dass er die Chance ergriff aus dem Namen einen Scherz zu machen. Er sprach davon, dass er alle seine Projekte nach sich selbst benannte, also erst „Linux“ und dann „git“. Zudem ist es ein kurzer und einigermaßen einzigartiger Name und zusätzlich auf einer Standardtastatur zu schreiben. Die erste Version von Git wurde am 07.04.2005 veröffentlicht.

Nutzen

Nutzen von git

Git ist sehr hilfreich, um Änderungen an Dateien zu verwalten, erleichtert die Zusammenarbeit im Team und die Organisation von Entwicklungsprozessen. Dadurch wird es hauptsächlich in der Softwareentwicklung eingesetzt.

1. Versionsverwaltung

In Git gibt es sogenannte Commits. Mithilfe dieser Commits speichert man jede Änderung, wodurch man ältere Versionen eines Projekts wiederherstellen kann, Änderungen im Team oder mit anderen vergleichen kann und nachvollziehen kann, wer was und wann geändert hat. Dies kann besonders hilfreich in der Teamarbeit sein, um Konflikten aus dem weg zu gehen und strukturiert zu arbeiten.

2. Arbeiten mit Branches

Zusätzlich zu den Commits können auch verschiedene Branches genutzt werden. Branches sind sogenannte Entwicklungszweige. Sie sorgen dafür, dass man einen neuen Code isoliert testen kann, mehrere Personen gleichzeitig an unterschiedlichen Funktionen arbeiten können und dass Fehlerbehebungen sich getrennt vom Hauptprojekt durchführen lassen. Am Ende können die verschiedenen Branches wieder zusammengeführt, also gemerged, werden.

3. Zusammenarbeit im Team

Wie in den oberen Punkten schon erwähnt ermöglicht es git, dass mehrere Personen gleichzeitig am selben Projekt arbeiten können. Einige Vorteile sind, dass jeder Entwickler eine vollständige Kopie des Repositories. Zusätzlich können Änderungen über Push und Pull synchronisiert werden. Zudem können Konflikte schnell erkannt werden und gezielt gelöst werden, da man zum Beispiel genau sehen kann, was verändert, wann es verändert wurde und von wem es geändert wurde. Durch diese Funktionen bleibt der Code stets konsistent und organisiert.

4. Nachvollziehbarkeit und Kontrolle

Durch die Historie, also durch die erstellten Commits, bietet Git lückenlose Dokumentation, einfache Fehleranalyse und die Möglichkeit, zu früheren Zuständen zurückzukehren.

5. Sicherung und Wiederherstellung

Während der Arbeit an einem Projekt, existieren mehrere Kopien eines Projekts. Das bedeutet es gibt eine hohe Datensicherheit, der Schutz vor Datenverlust ist gegeben und eine schnelle Wiederherstellung nach Fehlern oder Problemen ist dadurch möglich.

6. Flexibilität und Integration

Git lässt sich gut mit vielen Entwicklungswerkzeugen kombinieren und unterstützt somit große Projekte, unterschiedliche Programmiersprachen und automatisierte Tests und Deployment-Prozesse. Dadurch ist Git heute ein zentraler Bestandteil moderner Softwareentwicklung.

Kurz gesagt:

Git ist ein sehr gutes Programm um mit mehreren Personen zusammen an einem Projekt zu arbeiten und bietet zahlreiche Werkzeuge, die Struktur und Ordnung dabei sicherstellen. Wichtig zu erwähnen ist auch die leichte und zuverlässige Fehler, die durch die History ermöglicht wird.
