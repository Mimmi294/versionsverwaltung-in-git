Initialisierung eines Repositorys

Zu Beginn installierte ich zunächst git und befolgte die Anweisungen auf folgendem Link.
Gerade zu beginn ist es ratsam mit der Benutzeroberfläche GitHub Desktop zu arbeiten. GitHub Desktop greift auf die Funktionen und Daten von git zu und stellt diese Vereinfacht da, was gerade für Anfänger wesentlich einfacher sein kann, um sich zurecht zu finden.
Da ich die einzelnen Schritte nur abstrakt erkläre, verlinke ich spezifischere Anleitung als Hilfestellung.
Um mit meinem Projekt zu starten, initialisierte ich ein neues Repository. Das Repository bezeichnet mein gesamtes Projekt, inklusive des Codes, verschiedener Anhänge, den Versionsverlauf und organisatorische Informationen, die git helfen das Projekt zu verwalten.
Nachdem das Repository nun erstellt ist, befinden sich zunächst keine inhaltsbezogenen Daten darin - lediglich organisatorische Dateien für die Strukturierung des Projekts. Nach der Initialisierung ist das Repository vorerst nur lokal gespeichert, was dazu führt, dass es nicht ohne weiteres von anderen Geräten einsehbar ist.
